# 🎭 مافیا

بازی آنلاین مافیا با اتصال به تلگرام.

## هدف پروژه

ساخت یک بازی آنلاین مافیا که بازیکنان از طریق ربات تلگرام وارد شوند و بازی اصلی داخل Web App اجرا شود.

- ورود بازیکن

- باز کردن Web App

- ساخت اتاق
- ورود به اتاق
- لابی

- ویس چت

## دسته‌های بازی

- شهروند
- مافیا
- مستقل

هر دسته می‌تواند نقش‌های مختلف و قابلیت‌های اختصاصی داشته باشد.

## نقش‌ها

نقش هر بازیکن کاملاً خصوصی است.

هر بازیکن فقط نقش خودش و اطلاعاتی را که طبق قوانین بازی مجاز است مشاهده می‌کند.

## پروفایل

هر بازیکن می‌تواند داشته باشد:

- نام کاربری
- آواتار
- تعداد بازی‌ها
- تعداد بردها
- تعداد باخت‌ها
- آمار عملکرد

## اتاق بازی

هر بازی در یک اتاق مستقل اجرا می‌شود.

اتاق باید بتواند:

- بازیکنان را مدیریت کند
- ظرفیت مشخص داشته باشد
- لابی داشته باشد
- بازی را شروع کند
- وضعیت بازی را ذخیره کند
- مراحل بازی را کنترل کند

## چرخه بازی

11. بررسی نتیجه
12. ادامه بازی تا مشخص شدن برنده

## ویس چت

ویس چت داخل بازی خواهد بود و دسترسی بازیکنان به صدا باید بر اساس مرحله و قوانین بازی کنترل شود.

## قوانین توسعه

- هیچ قابلیت قبلی بدون دلیل حذف نشود.
- تغییرات فقط روی بخش موردنظر انجام شود.
- ساختار فایل‌ها بدون دلیل تغییر نکند.
- قبل از تغییر کدهای مهم، ساختار فعلی بررسی شود.
- هر قابلیت مرحله‌به‌مرحله اضافه و تست شود.
- قابلیت‌های جدید نباید باعث خراب شدن قابلیت‌های قبلی شوند.
- اطلاعات خصوصی نقش‌ها نباید به بازیکنان دیگر نمایش داده شود.
- ساختار پروژه باید قابلیت توسعه برای بازی‌های بزرگ‌تر را داشته باشد.
